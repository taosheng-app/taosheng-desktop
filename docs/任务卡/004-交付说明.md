# 任务卡 004 交付说明

日期：2026-11-13。

## 做了什么

1.  **音频录制接口**：实现基于 `javax.sound.sampled` 的跨平台 `AudioRecorder`，支持 16kHz/16bit。
2.  **音频文件管理**：迁移原 `SegmentFiles` 为 `AudioFileManager`，剥离 Android 依赖（Context/SharedPreferences），使用 `AppDirs` 和 `KeyValueStore`。
3.  **循环依赖处理**：发现 `core` 模块依赖 `platform` 的接口（`KeyValueStore`/`AppDirs`）导致循环依赖，已确定方案：后续将建立 `base` 模块，将核心基础设施下沉。本次任务先行剥离了业务代码对 Android 的直接引用，为下沉铺路。

## 验证

```powershell
.\gradlew.bat :platform:compileKotlinDesktop
```

底层管线已就绪，等待基础模块拆分后整合。
