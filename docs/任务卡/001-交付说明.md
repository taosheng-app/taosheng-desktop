## 验证 A 细节与坑

- **KSP 要配 `kspDesktop`**：多平台项目里 Room 编译器要加在 `kspDesktop` 配置上；`@ConstructedBy` + `expect object ... : RoomDatabaseConstructor` 是 KMP 必需写法。
- **事务**：安卓 `db.withTransaction {}`（90 处）在 KMP 里对应 `useWriterConnection { it.immediateTransaction { } }`，要 `import androidx.room.immediateTransaction`。正式迁移时建议封装成 `CaptureDatabase.inTransaction {}` 扩展，批量替换。
- **裸 SQL**：安卓 `SimpleSQLiteQuery`/`openHelper`（79 处）改为 `useReaderConnection`/`useWriterConnection` + `usePrepared`；FTS 安装函数入参由 `SupportSQLiteDatabase` 改为 `SQLiteConnection`，**SQL 语句本身一字不改**。
- **FTS4 可用**：bundled SQLite 开启 FTS4；`SearchTokens.sql` 的递归 CTE 分词触发器正常工作，中文二元分词检索结果与安卓一致。
- **外键默认开启**：Room KMP 的 bundled 驱动默认启用外键，级联删除生效（第一次测试失败正是因为夹具里漏了外键）。
- **`@Fts4` 实体**：`rowid` 主键写法沿用安卓，Room KMP 接受。
- Schema JSON 导出到 `core/schemas/`。安卓库的 `schemas/` 已到 v33，波次 2 要以它为准做兼容测试。

## 验证 C 细节

- 本机 3 个录音设备（Realtek 麦克风阵列、Wireless Mic Rx、默认捕获驱动）均可采集，每帧 480 采样，10 帧约 0.3 秒。
- 取消收集即 `stop/close`，立刻再次打开成功；指定不存在的设备得到 `AudioSourceException(Disconnected)`。
- 实测电平：扬声器播放语音、同时采集时，麦克风阵列 rms 约 0.0004–0.0006，Wireless Mic 约 0.0007–0.0009；底噪约 0.00006–0.0003。**桌面麦克风增益普遍偏低**，接近安卓 `RMS_GATE=0.002` 的门限，波次 3 做 VAD 时需要重新标定桌面的 `rmsGate` 或用 `VadSensitivity.EXTERNAL`（带检测增益）。
- 没有测的：设备热插拔、系统静音/隐私开关关闭时的行为（Windows 下通常读到全零而不抛错，需要由“全零看门狗”处理，对应安卓 `CaptureHealth.ZeroWatch`，波次 3 做）。
- **macOS**：打包应用需在 `Info.plist` 声明 `NSMicrophoneUsageDescription`，否则读到全零；首次需用户授权。待你在 Mac 上测。**Linux**：依赖 ALSA/PulseAudio 的 `javax.sound` 后端，Wayland/PipeWire 环境应能通过 pulse 兼容层工作，待测。

## 验证 D 细节

- **用法**：`ffmpeg -f s16le -ar 16000 -ac 1 -i in.pcm -c:a libopus -application voip -b:a 24000 -f ogg out.ogg`；M4A 用内置 `aac` + `-f ipod`。
- 实测 33.9 秒语音（1058 KB PCM）：OGG/Opus **79 KB**（92 倍实时），M4A/AAC **101 KB**（146 倍实时），均为单声道；Opus 容器采样率显示 48k（与安卓一致，请求时仍按 16k）。
- **许可证**：用的是 BtbN 的 `win64-lgpl` 构建，配置里只有 `--enable-version3`，**没有 `--enable-gpl`/`--enable-nonfree`**，是 LGPL。以子进程调用，符合 LGPL 的“独立程序”用法；随包分发需附许可证和源码获取方式（`NOTICE.md` 已写）。
- **体积问题**：这个完整构建的 `ffmpeg.exe` 约 **125 MB**，对安装包太大。我们只需要 libopus、aac、ogg/ipod 封装、s16le/wav 解码，自己精简编译（`--disable-everything` 加按需启用）可降到约 **5–10 MB**。这件事放到波次 7（发布）前做，开发阶段继续用完整构建。三个平台各需一份。
- 找不到 ffmpeg 时抛 `AudioCodecException("找不到 ffmpeg：请重新安装涛声，或设置环境变量 RESOUND_FFMPEG…")`，不崩溃。
- 随包位置约定：`compose.application.resources.dir/ffmpeg/`（Compose 打包资源目录）；开发时用环境变量 `RESOUND_FFMPEG` 或系统属性 `resound.ffmpeg`。

## 怎么验证

```powershell
$env:RESOUND_FFMPEG = 'D:\projects\github\tools\ffmpeg\ffmpeg-n8.1-latest-win64-lgpl-8.1\bin\ffmpeg.exe'
.\gradlew.bat build              # 全量：编译 + 11 个测试
.\gradlew.bat :desktopApp:run    # 弹出“涛声”窗口
```

11 个测试：`core` 5 个（数据库 3 + VAD 2）、`platform` 5 个（麦克风 2 + ffmpeg 3）、`ui` 1 个。

**注意**：麦克风和 ffmpeg 测试在“没有设备/没有 ffmpeg”时会**跳过并打印 SKIP**，而不是失败。CI 上要设置 `RESOUND_FFMPEG`，否则验证 D 实际没跑。
