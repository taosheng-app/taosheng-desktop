# 任务卡 005：转写、检索与声纹模块迁移

## 目标
将原 Android 项目中的 `transcribe`、`search`、`voiceprint` 业务模块迁移至桌面端 `core` 模块。

## 范围
1. **转写 (`transcribe`)**：迁移转写运行器接口与实现，仅实现豆包/OpenAI 兼容接口，暂存本地转写实现为 `AsrError.ModelMissing`。
2. **检索 (`search`)**：迁移检索逻辑与向量库接口。
3. **声纹 (`voiceprint`)**：迁移声纹模型加载与比对接口。

## 验收标准
1. 模块迁移后代码可通过 `:core:compileKotlinDesktop` 编译。
2. Windows 端通过关键链路逻辑（接口注入验证）。
3. 记录迁移中 Android 独有逻辑（如 NPU、原生 VAD）的处理方式。
