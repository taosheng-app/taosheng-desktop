# 006 交付说明

## 做了什么
1. 迁移了整理 (`digest`) 与 专题 (`topic`) 模块核心逻辑至桌面端。
2. 集成本地 Markdown 日志导出 (`diary`) 功能，基于只读 review 数据。
3. 实现基础的 read-only "问问本地记忆" (`Ask`) 功能。

## 如何验证
1. 运行 `gradlew.bat :core:compileKotlinDesktop` 验证模块完整性。
2. 验证 Digest→Topic 的基础业务链路在 `DesktopAppGraph` 与 UI 中已装配。
3. 验证本地 Markdown 导出功能。

## 遗留问题
1. **Model E2E**：整理逻辑虽编译通过，真实模型推理调用尚未进行端到端 E2E 验证。
2. **Unsupported**：`DigestThingExtraction`、特殊专题模板、Android 日志生成、推送与云端同步功能均不支持，UI 已做隔离与提示。
3. **交互**：部分业务功能依赖的对话/上下文/技能卡片等高级 UI 交互尚未实现。
