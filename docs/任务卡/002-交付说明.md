# 任务卡 002 交付说明

日期：2026-11-13。环境：Windows 11、JDK 21。

## 做了什么

`platform` 模块新增 7 个端口与桌面实现（包 `app.resound.platform`），共新增 23 个测试，全部通过：

| 端口 | 实现 | 对应安卓 |
|---|---|---|
| `AppDirs` | 三平台目录布局、`resound.home` 覆盖 | `filesDir` / `noBackupFilesDir` / `cacheDir` |
| `KeyValueStore` / `KeyValueStores` | `FileKeyValueStore`：JSON 文件、原子写、损坏降级 | `SharedPreferences` |
| `SecretStore` + `MasterKeyProvider` | AES-256-GCM；主密钥优先系统钥匙串，回退文件 | `digest/SecretStore`（Keystore） |
| `Scheduler` | 进程内调度 + 任务表落盘 | `WorkManager` |
| `Notifier` + `Channels` | `DesktopNotifier`：托盘气泡，无托盘走应用内队列 | `NotificationManager` |
| `Clock` | `Clock.System` | `System.currentTimeMillis` / `SystemClock.elapsedRealtime` |
| `NetworkMonitor` | 网卡轮询 | `ConnectivityManager` |
| `DesktopPlatform` | 一处装配上述全部 | `ResoundApp.onCreate` 的系统部分 |

另：`SecretStore` 与安卓同名同签名（`read/write/remove/has`），密文格式也一致（Base64(12 字节 IV + 密文)）。

## 迁移对照表（供波次 2+ 查阅）

### SharedPreferences → KeyValueStore

| 安卓 | 桌面 |
|---|---|
| `context.getSharedPreferences("x", MODE_PRIVATE)` | `platform.prefs.get("x")` |
| `prefs.getString/getInt/getLong/getBoolean/getFloat/getStringSet` | 同名，签名相同 |
| `prefs.edit().putX(..).commit()` / `.apply()` | 同名，`commit()` 返回是否落盘成功 |
| `prefs.contains/all` | 同名 |
| `registerOnSharedPreferenceChangeListener` | `addListener { key -> }` |

**差异**：类型不符时返回默认值而非抛 `ClassCastException`；`putX(key, null)` 等同 `remove`；`getLong` 能读 `putInt` 存的值；监听器不保证在主线程。

### WorkManager → Scheduler

| 安卓 | 桌面 |
|---|---|
| `CoroutineWorker.doWork()` | `scheduler.registerWorker("id") { ctx -> TaskResult }` |
| `Result.success/failure/retry` | `TaskResult.Success/Failure/Retry` |
| `enqueueUniqueWork(name, KEEP/REPLACE/APPEND_OR_REPLACE, req)` | `enqueueUnique(name, req, ExistingPolicy.Keep/Replace/AppendOrReplace)` |
| `enqueueUniquePeriodicWork(name, KEEP/UPDATE, req)` | `enqueuePeriodic(name, req, Keep/Update)`，最小 15 分钟 |
| `setInitialDelay` / `setBackoffCriteria` / `addTag` | `TaskRequest.initialDelayMillis` / `backoff` / `tags` |
| `NetworkType.CONNECTED/UNMETERED` | `NetworkRequirement.Any/Unmetered`（桌面两者等价） |
| `workDataOf` / `inputData` | `TaskRequest.input` / `ctx.input`（只允许 String/Int/Long/Boolean） |
| `cancelUniqueWork` / `cancelAllWorkByTag` | `cancel(name)` / `cancelByTag(tag)` |
| `getWorkInfos` / `WorkInfo.State` | `status(name)` / `observe(name)` / `TaskState` |
| `setExpedited` | `expedited = true`（同时到期时优先） |
| `setForeground` / `getForegroundInfo` | **没有对应物**：桌面进程常驻，直接去掉；进度提示改发 `Notifier` 通知 |

行为：退避默认指数、起始 30 秒、上限 5 小时；停机期间错过的周期任务**只补跑一次**；重启后被打断的 Running 任务重新排队；未注册的 worker 直接 Failed 而不是挂起。

## 怎么验证

```powershell
.\gradlew.bat :platform:desktopTest      # 全部 platform 测试
```

- 调度器测试用假时钟，没有真实等待；并做了一次破坏性检查（把指数退避改成固定延迟，测试按预期失败，还原后通过）。
- Windows 真实钥匙串往返已实测：凭据管理器写入、读回一致（32 字节），无回退；条目已清理。
- **自动化测试不碰系统钥匙串**：`DesktopPlatform.create(..., masterKeys = FileMasterKeyProvider(...))`。第一版测试曾往真实凭据管理器写了一条，已发现并清除，之后改为可注入。

## 平台差异与回退

- **钥匙串**：Windows 凭据管理器已实测；macOS 钥匙串、Linux Secret Service 未测（Linux 无桌面会话或没装 gnome-keyring/KWallet 时会回退到文件密钥：`<data>/keys/<alias>.key`，POSIX 权限 600，Windows 上用仅所有者的 ACL）。回退只通过 `onKeyFallback` 报告一次，界面可据此提示。
- **通知**：Windows 托盘气泡已写，但**只在无头环境之外才会真实弹出，我没有在本机肉眼确认气泡**（测试用的是记录后端）；无托盘的 Linux 桌面（如部分 GNOME 版本）走 `DesktopNotifier.fallback` 流，需界面层订阅展示。macOS 上 AWT 托盘气泡表现为通知中心条目，待测。
- **网络**：桌面无法可靠判断计流量网络，`Unmetered` 视同 `Any`（有可用网卡即在线）。以前“仅 WiFi”开关在桌面上实际不起作用，设置页要么隐藏、要么改文案，留给界面卡决定。

## 遗留问题

- 托盘图标现在是空白 16×16 占位图，正式图标和菜单属于波次 7。
- 点击气泡回到主窗口依赖 AWT 的 `ActionListener`，在部分平台点击事件不触发，需要真机确认。
- `NetworkMonitor` 只看网卡，不能发现“有网卡但出不了外网”；业务请求失败时靠重试兜底。
- `KeyValueStore.apply()` 的异步落盘只在 `flush()`/`shutdown()` 或下次写入时保证落盘，进程被强杀会丢最近一次 `apply()`；关键数据请用 `commit()`（与安卓行为一致，安卓同样可能丢）。
- 调度器目前一个 JSON 文件整体重写，任务数到几百条以上需要改成增量；现状是几十条量级。
