# 005 交付说明

## 做了什么
迁移并适配了转写 (`transcribe`)、检索 (`search`) 与声纹 (`voiceprint`) 业务模块至 KMP Desktop：
1. 实现音频文件导入管线，支持 WAV/PCM 原生解析与其它格式 FFmpeg 解码（需本地安装 FFmpeg）。
2. 支持 Doubao/Custom 云端 ASR 调用。
3. 实现本地 FTS 关键字检索及可选 Opt-in BGE 语义检索。
4. 实现本地 "我" 的声纹录制与匹配模型（CAM++，Apache-2.0 许可）。

## 如何验证
1. 运行 `gradlew.bat :desktopApp:compileKotlinDesktop` 确保编译通过。
2. Windows 下构建并验证 MSI 包安装及 tray 启动。
3. 验证本地文件导入与手动触发云端 ASR。
4. 验证语义检索模型 Opt-in 下载与索引流程。

## 遗留问题
1. **本地 ASR**：桌面版暂不支持本地语音识别，调用均报 `AsrError.ModelMissing`。
2. **硬件/服务 E2E**：Tray/单实例/autostart 仅代码逻辑实现，未进行 GUI 环境的实机交互验证。
3. **环境依赖**：压缩音频转写需要本机安装 FFmpeg 并配置于 PATH。
