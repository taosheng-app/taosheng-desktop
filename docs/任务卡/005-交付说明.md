# 005 交付说明

## 做了什么
迁移了原 Android 项目的转写 (`transcribe`)、检索 (`search`) 与声纹 (`voiceprint`) 业务模块，并适配了桌面端的存储接口 (`KeyValueStore`)。

## 如何验证
1. 运行 `./gradlew :core:compileKotlinDesktop` 验证模块依赖与代码正确性。
2. 确认业务接口（如 `EmbeddingStore`，`TranscribeContract`）已正确对接到桌面端的 `core` 数据层。

## 遗留问题
1. **ASR 实现**：本地语音识别模型加载逻辑（针对 NPU/Android 特性）未实现，当前仅保留了通用接口与存根。
2. **检索/声纹依赖**：检索模块对本地 SQLite 函数依赖可能需要后续进一步适配。
