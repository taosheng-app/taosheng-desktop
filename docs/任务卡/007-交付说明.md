# 007 交付说明

## 做了什么
1. 实现桌面应用 Shell，包含托盘图标 (Tray)、窗口管理、单实例运行控制 (SingleInstanceLock) 与 OS 原生开机自启 (AutoStart) 支持。
2. 配置 Gradle 打包任务，支持 Windows MSI 构建 (`gradlew.bat :desktopApp:packageMsi`)。

## 如何验证
1. 在 Windows 上运行安装 MSI 并验证托盘功能与窗口生命周期。
2. 验证单实例控制逻辑与开机自启行为（目前仅代码实现，需实机验证）。

## 遗留问题
1. **跨平台构建**：目前仅验证 Windows MSI 构建，macOS (DMG) 和 Linux (DEB) 打包需要相应 OS 的原生环境。
2. **GUI 验证**：Tray 图标显示、托盘关闭行为及开机自启在当前的 Headless 运行环境中无法直接进行 GUI 交互验证。
