# 任务卡 007：桌面外壳与发布

## 桌面外壳

- Compose Desktop 外壳包含主窗口、涛声托盘图标、“打开涛声/退出”菜单；窗口关闭时托盘可用则隐藏，否则退出。
- 第二实例通过 data directory 下的文件锁与 loopback activation 通知现有实例显示窗口。
- `DesktopAutoStart` 提供 Windows HKCU Run、macOS LaunchAgent、Linux XDG autostart 实现；安装包路径未注入时禁用设置，避免写入无效命令。
- DesktopPlatform 在应用退出时统一 shutdown。主页提供当前用户级开机自启开关；开发运行时因没有安装包可执行路径而禁用。单实例唤起、自启注册表写入和系统托盘尚未在真实桌面交互中人工验证。

## 发布

`desktopApp/build.gradle.kts` 配置 MSI、DMG、DEB，版本 `1.0.0`。原生包需在对应操作系统构建。

Windows 验证通过：

```text
cmd.exe /c "gradlew.bat :desktopApp:compileKotlinDesktop --console=plain"
cmd.exe /c "gradlew.bat :desktopApp:packageMsi --console=plain"
```

生成文件：`desktopApp/build/compose/binaries/main/msi/TaoshengDesktop-1.0.0.msi`。

当前 Windows 环境无法验证 macOS DMG 和 Linux DEB；需要分别在 macOS/Linux CI runner 或物理机运行 Compose 的 package 任务。
