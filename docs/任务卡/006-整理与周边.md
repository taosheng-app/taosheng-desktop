# 任务卡 006：整理与周边业务模块

## 目标
迁移涛声桌面版的整理与周边功能模块。

## 范围
包括 `digest`、`topic`、`things`、`ask`、`review`、`skills`、`envsound`、`diary`、`redo`、`context`、`importer`、`recordings`、`backup`、`push`、`update`、`onboarding`。

## 验收标准
1. 模块代码成功编译。
2. 演示功能：文字→事件生成（`Digest` → `Topic`）。
3. 记录迁移中 Android 特定交互（如 Backup/Restore 兼容性、通知权限等）的适配方案。
