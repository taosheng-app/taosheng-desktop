## 桌面文本→事件链

普通 Digest 会把选定转写文本交给 `DigestPrompt` 解析并持久化事件与待办项。Topic 的 `TopicKind.Normal` 路径复用 Digest 提示和解析逻辑：`TopicGenerator.generate` 得到事件/事项，`TopicEngine.run` 在数据库事务中写入 `MemoryEventEntity`，关联待办项并标记原话已整理。这个路径已纳入桌面 `core` 源集并通过 `:core:compileKotlinDesktop` 编译。

桌面主窗口提供模型密钥保存、连接测试、粘贴文本、手动整理及数据库事件流显示，复用生产 `DigestRunner` 写入 Room。事件列表支持勾选多个事件、预览影响与冲突，再确认创建普通专题；`RoomTopicRepository` 转移原事件与事项，`TopicEngine` 复用生产 Digest 解析链生成纪要，失败专题可手动重试。`DesktopTopicService` 只暴露普通专题操作，特殊专题明确不支持。桌面当前由显式操作直接调用 TopicEngine，持久 scheduler 尚未启动后台任务。主窗口另提供日期范围 Markdown 日记导出，包含本机事件、事项、原话及已保存的每日回顾；每日回顾只读适配既有 Room 记录，桌面端不生成新回顾、不推送、不同步到云端。需要可用模型密钥和网络；尚未完成人工端到端演示。编译通过，Windows MSI 已重建。

## Android 交互迁移

- Room 使用 KMP 数据库及桌面事务 helper；Android `withTransaction` 不再直接依赖。
- WorkManager 后台任务转为 platform scheduler；没有 Android 前台服务、电量约束、精确闹钟或运行时通知权限。
- 备份/恢复和导入导出应通过桌面文件路径与系统文件选择器接入；Android `Uri`/`Context` 不作为桌面业务契约。
- 通知使用桌面 notifier，受操作系统通知设置影响；不模拟“已显示”。
- `DigestThingExtraction` 可选 revision 工作流暂未接入桌面 Digest；普通事件整理继续工作。
- 日记导出读取既有每日回顾，不触发大模型；每日回顾生成、定时通知、推送、云端同步和设置暂未接入桌面。
- 会议/培训/通话/口播等特殊 Topic 需要 Android skill/import 运行时的路径明确抛出“桌面版暂不支持该专题类型”，不误报生成成功。

## 尚未接入桌面交互的领域

下面这些领域虽有迁移代码或平台基础，但当前主窗口没有可用工作流，不能算桌面功能已完成：

- `ask`：桌面有只读单轮问答入口，先用本地 FTS/已启用语义索引取最多 8 条资料，再由用户显式发送给大模型；展示模型返回且校验过编号的引用。问答会话不持久化，没有工具调用、寻物/地点问答或确认式修改能力。
- `skills`、`envsound`：日记导出没有技能卡，环境声场景和相关装饰没有桌面流程。
- `redo`、`context`：没有完整的撤销/重做与上下文操作界面。
- `importer`、`recordings`：可手动开始/停止麦克风录音并将本地 PCM 加入持久 ASR 队列；上传需另行点击确认。尚无自动分段、后台持续录音或通用资料导入流程。
- `backup`：没有桌面备份/恢复操作。
- `push`：平台通知适配器已存在，但每日回顾推送和提醒调度未接入。
- `update`、`onboarding`：没有桌面自动更新和新用户引导流程。
